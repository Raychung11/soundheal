## Phase 1 — Initial scaffold

Native PHP 8.2+ modular architecture, no framework, designed for Hostinger.

**Folders**

```
config/        app.php, db.php, payment.php (Billplz), ai.php (OpenAI / WhatsApp)
includes/      bootstrap, auth, csrf, session, role, functions, header, navbar, footer, admin_layout
public/        landing, about, experiences, events, membership, contact, login, register, logout
member/        dashboard, my_bookings, my_tickets, my_membership, profile, wellness_journey,
               book_event, checkout, subscribe
admin/         dashboard, events + event_form, bookings, members, payments, checkin, content,
               testimonials, corporate_leads, reports
api/           billplz_create, billplz_webhook (HMAC verified), ai_chat (OpenAI + fallback),
               qr_validate, whatsapp_webhook
assets/        Tailwind via CDN, Cormorant Garamond + Inter, navy + gold + warm beige
database/      schema.sql with 14 tables + audit_logs + seed admin & 3 plans
```

**Security**

- 100% PDO prepared statements
- `password_hash` / `password_verify` w/ auto rehash
- Hardened sessions (HttpOnly, SameSite=Lax, strict mode, periodic ID rotation)
- CSRF on every state-changing form
- Role guards (`require_login`, `require_admin`, `require_staff_or_admin`)
- Webhook signature verification
- `.htaccess` denies direct access to `config/`, `includes/`, `logs/`, `database/`
- Audit log on every meaningful action

### Bug fixes during this phase

- `c1e5c07` — **405 Not Allowed** on `/admin/home_settings.php`: the `.htaccess`
  Force-HTTPS rewrite was bouncing POSTs that nginx then served as 405.
  Disabled (Hostinger's nginx already terminates SSL). Field-name mismatch
  in the upload handler also fixed. Upload caps lowered to fit shared limits
  (home 8 MB, content 16 MB).
- `95bc021` — Cover images in `uploads/content/` were being denied along with
  the audio. Restricted the deny rule to audio extensions only and added
  graceful broken-image fallbacks across the library page.
- `07d1024` — Track covers can now be set by uploaded file *or* pasted URL
  (Unsplash / Pexels). Recommended size hint inline: 1200 × 900 px (4:3),
  JPEG/WebP, under ~500 KB.
- `d2e4ee4` — Player buttons were inside an opacity-0 hover overlay (hidden
  on touch). Pinned a permanent gold play button to every card. Track JSON
  moved out of the `x-data` attribute (where stray quotes broke Alpine) into
  `window.__SH_LIBRARY`. Admin track-edit flow added (Edit / Publish / Delete
  per row).

## Phase 4 — Marketing analytics

**Tracking** (`includes/marketing.php`)

- `track_view()` runs on every public/member HTML render via `header.php`
- Captures: path, referrer (host + raw), user agent, hashed session id
  (unique-visitor count), hashed IP (privacy), UTM tags, is_bot flag
- Skips non-GET, /api/, CLI, and admin/staff users (admin layout sets
  `$skipTracking = true`)

**Schema** — `database/migrations/005_phase4_marketing.sql`

```sql
page_views (path, referrer, referrer_host, user_agent, ip_hash, session_token,
            utm_source, utm_medium, utm_campaign, is_bot, created_at)
```

**Dashboard** — `/admin/marketing.php` (sidebar entry "Marketing")

- Range toggle: **7 / 30 / 90 days**
- KPI strip:
  - Views · Unique visitors

  - Sign-ups (with free-trial sub-count)
  - Paid bookings · Revenue
  - **Visitor → sign-up %** · **Sign-up → booking %**

- Top 10 pages + Top 10 referring hosts

## Phase 4.x — Member-refer-member program

**Schema** — `database/migrations/006_phase4_referrals.sql`

- `users.referral_code` (unique 6-char) + `users.referred_by_user_id`
- `referrals` table: referrer/referee user ids, status
  (`signed_up | converted | rewarded | cancelled`), reward_type, reward_amount,
  signed_up_at / converted_at / rewarded_at, unique pair index
- `site_settings`: `referral_signup_trial_days = 7`, `referral_program_eyebrow`,
  `_headline`, `_subheadline`

**Helper** (`includes/referrals.php`)

- `referral_code_for_user()` — lazily mints + persists a 6-char code
- `referral_link_for_user()` — `/public/register.php?ref=…` URL
- `capture_referral_cookie()` — 30-day HttpOnly cookie carries attribution
  through navigation and form errors
- `apply_referral_on_signup()` — on register, sets `referred_by_user_id`,
  inserts a `referrals` row (UNIQUE so re-runs are safe), and extends **both**
  the referrer's and the new user's `trial_ends_at` by N days
  (capped at +180 days, idempotent)

**Member experience**

- `/public/register.php?ref=A3F9C2` shows a warm "&lt;First name&gt; invited
  you" banner, swaps the title to "Welcome, gently", and forces trial mode
- `/member/refer.php` (new) — hero share card with copy-link, WhatsApp /
  Email / Twitter / native Web Share buttons, plain referral code, stats
  strip, and history table of friends who've joined
- Navbar: "Refer" link for signed-in members
- Member dashboard: full-width gold-border tile teasing the program

**Admin**

- `/admin/marketing.php` gains a "Referral sign-ups" KPI + "Top referring
  members" table
- `/admin/referral_settings.php` (sidebar entry "Referral program") — edit
  eyebrow / headline / subheadline copy, set trial days awarded per sign-up
  (0–60), see live stats: total / rewarded / trial days given (both sides) /
  last 7 days
